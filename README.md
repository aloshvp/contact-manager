# 📇 React Contact Manager

A simple and elegant **Contact Manager App** built using **React** and styled with **Bootstrap**. It allows users to add, validate, and delete contacts with real-time form handling and validation.

---

## ✨ Features

- ✅ Add contacts with name and email
- 🔎 Validates:
  - Name (alphabets and spaces only)
  - Email (basic email format)
- 🗑️ Delete contacts from the list
- 🎨 Styled using Bootstrap 5
